## Development Workflow

### Getting Started

1. Clone the repository
2. Check out the appropriate feature branch
3. Install dependencies (once a package manager is configured)

### Branch Conventions

- Feature branches should follow the pattern: `claude/<description>-<id>`
- Commit messages should be clear and descriptive
- Push changes with `git push -u origin <branch-name>`

### Code Style

- Follow the established conventions of whichever language/framework is adopted
- Keep code simple and avoid over-engineering
- Prefer editing existing files over creating new ones
